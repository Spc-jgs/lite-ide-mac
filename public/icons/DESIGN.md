## 风格由现有资产决定

基准是仓库已有的 JetBrains 新 UI 图标。布局、类型颜色和交互不能因为新加一个按钮而再长出另一套。新增图标先检查现有名字与语义；确实缺失才补一个文件。来源逐个登记在 [SOURCES.md](SOURCES.md)，唯一注册表是 `Icon.svelte` 的 `ICON_NAMES`，画廊自动遍历它。

这次盘点的起点是 **67 个界面注册名、108 个 SVG 文件**，文件类型和编辑器 gutter 图标不全部经过 `Icon`。新增构建后是 68 个注册名、109 个 SVG。既有 SVG 的形状和文件内容保留。

## 按用途分工

| 用途 | 入口与尺寸 | 颜色与状态 |
|---|---|---|
| 工具窗身份 | `Icon`；16px 图形，26px 导轨按钮 | 默认中性，选中由按钮底表达；角标另表示改动或任务数量 |
| 工具栏动作 | `Icon`；16px 图形，24px 按钮 | 普通动作使用 currentColor；运行 / 调试 / 停止保留现有语义颜色 |
| 文件与目录身份 | `FileGlyph`；16px 图形 | 文件类型 / 源码根 / 包等保留原色；文件名颜色表示 Git 状态，两者不混用 |
| 编辑器 gutter | 对应原有 CSS 背景图 | 保留原版尺寸：断点和书签是 14px，跳转标记按原有 16px；不为了“统一”拉伸 |
| 结果与告警 | 共用原有 check / error / warn | 图形和文案一起表达，不能只靠红绿；背景色不代替图形语义 |
| 应用图标 | `design/icon/make_icon.py` | 独立的品牌资产，工具栏改动不触碰 |

## 几何与渲染

- 16×16 viewBox；图形边缘至少留半像素，水平 / 垂直 1px 线尽量落在半像素坐标。自绘补充保持约 1px 的视觉线重，不给已有上游路径套统一 stroke-width。
- 中性线条使用既有 `#CED0D6`；单色图标由 CSS mask 取形状，最终颜色来自控件的 `currentColor`。需要圆润转折时沿用现有自绘图标的 round join，不增描边、阴影、渐变或发光。
- 有填充与描边两种颜色，或颜色本身表示类型的图标，走背景图原色渲染。不能因为外形是“线性”就走 mask；mask 只保留透明度，深色填充也会变成实心块。
- 图形不随 hover 放大、不改变布局；hover / selected / pressed / disabled / busy 复用 `.ibtn` 与语义令牌。忙态延迟沿用全局 150ms，不在 SVG 里嵌动画。
- SVG 文件放 `public/icons/`，不内联进产品 JS；开发画廊与独立设计稿展示 SVG，不代表产品入口增加同样大小的字符串。

## 本次决定

| 图标 | 处理 | 依据 |
|---|---|---|
| 构建 `build` | IDEA 原版 New UI 锤子 | 从本机 IDEA 的 `expui/build/build_dark.svg` 原样提取，并用图标映射表核对其编译动作语义；不再自绘 |
| 数据库 `database` | 只改渲染，不改 SVG | 文件有 `#2F2936` 填充和 `#B589EC` 描边，原来未列入背景图名单，mask 把内部层次压成实心；恢复原色保留既有设计 |
| Git 标签 `tag`、AI `ai` | 保留 | 两份自绘资产均为 16px / 1px 中性风格，没有发现需要重绘的具体依据 |
| 其余上游图标 | 保留 | 不因新增图标更换既有轮廓、颜色或文件；不能把“来自不同子目录”当成不统一的证据 |

构建图标只表示项目构建；不用于“折叠”“打包发布”或“执行某个 Maven 目标”。它放在运行配置左边，二者靠间距分组；禁用状态和忙态不改变点击目标位置。

构建图标最终遵循用户“直接使用 IDEA”的要求，从已安装的 IDEA 中只读提取原版资产；不新增图标库、字体或网络依赖。后续发现确切不一致时，先记录具体文件、当前渲染和触发场景，再决定只修渲染还是重绘。

## 检查与维护

每次加图标检查：注册名唯一、资源存在、来源记录、语义不重复、渲染路径正确、16px 下可辨认；放回实际工具栏与相邻图标并排看。`?gallery` 自动展示全部注册图标，构建图标在同一排动作中比较，不单独做一套按钮。

本次完整资产对照位于 `design/workbench-2026-10-29/Icons.html`。其中缩略图直接来自实际 SVG；原型 `Main.html` 的既有图标也使用仓库原件，不再用手画替身。静态对照不能代替真实 `.app` 的材质与显示缩放验收。
