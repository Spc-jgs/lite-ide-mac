## 截图问题一：侧栏无法用导轨收起

**已验证的代码事实：**

- `src/lib/shell/Rail.svelte:65` 起的侧栏视图按钮，点击全部调用 `layout.showSide(b.v)`；草稿按钮也调用 `showSide("scratch")`。
- `src/lib/state/layout.svelte.ts:98` 的 `showSide` 总是设置 `sidebar = true`。因此点击当前亮着的图标，结果仍然是展开。
- `Rail.svelte:49` 的注释记录删除独立开关，理由是“点导轨上当前亮着的那个视图就是收起”；这与实际处理函数矛盾。
- `App.svelte:989` 根据 `layout.sideShown` 控制侧栏；`App.svelte:1210` 已经有去掉侧栏列、保留 34px 导轨的布局。无需重做外壳布局。
- 现有菜单“侧边栏 / ⌘1”调用 `toggleSidebar`，它可以把 `sidebar` 改为 `false`。

**直接状态探针：** 在裸 Node 的 runes loader 下调用真实状态模块，`sidebar=true、sideView=files → showSide(files)` 仍为 `true/files`；随后 `toggleSidebar(true)` 得到 `false/files`。这验证的是状态和调用链，没有冒充真 `.app` 的点击验收。

**原因：** 删除专用开关后，导轨仍只负责“去某个视图”，没有承担承诺的“再点收起”。同样的问题影响文件树、Git、Maven / Gradle、结构、数据库、AI 和草稿。这里描述的是当前代码行为，不据此归责具体作者。

**建议行为：**

| 当前状态 | 点击 | 结果 |
|---|---|---|
| 侧栏收起 | 任意侧栏视图 | 展开对应视图 |
| 文件树展开 | 文件树 | 收起侧栏，导轨留在原位 |
| 文件树展开 | Maven | 原地切换到 Maven，宽度不变 |
| Maven 展开 | Maven | 收起侧栏 |
| 任意视图展开 | 当前视图 | 收起，不停止后台工作 |

保留 `showSide` 的“强制显示”语义，供程序导航使用；导轨增加有明确用途的切换动作。不要直接改变 `showSide`，否则外部要求显示面板时可能反而把它藏起来。`⌘1` 本轮不顺手改成另一种语义；它现在切换整个侧栏，需要另行决定是否完全对齐 IDEA 的 Project 快捷键。

不恢复另一个全局侧栏开关。文件树头可以采用工具窗统一的 `—` 隐藏动作：它与导轨是同一状态的直接操作，而非第二套视图选择器；底部工具窗已有这个约定。是否在所有侧栏头统一增加，作为独立设计选择，不能只给文件树打补丁。

“折叠全部”只折目录；“隐藏工具窗”收起整个侧栏；`×` 关闭对象。三者图标和 tooltip 必须分开。Esc 从工具窗回编辑器，不能顺手当关闭侧栏。

## 截图问题二：标题栏要不要构建按钮

**建议增加，在运行配置左侧，使用锤子图标。**

已验证：`RunWidget.svelte:70` 只渲染运行配置、运行、调试、停止；`keymap.ts:405`、`menu-actions.ts:193` 和 Rust 菜单已有“构建项目 / ⌘F9”；`runs-ops.ts:49` 已有 `buildProject(false)`，复用现有任务运行、编译错误树与结果通知。现有构建状态测试本轮 10 / 10 通过。**缺的是可发现的入口，不是整个构建能力。**

拟定排列：`[构建]  [当前运行配置 ▾] [运行] [调试] [停止]`。

| 动作 | 作用范围 | 建议反馈 |
|---|---|---|
| 构建项目 | 当前项目，沿用现有构建语义 | tooltip“构建项目 · ⌘F9”；运行时保留图标位置，150ms 后显示忙态；防止重复点击；结果沿用构建输出和通知 |
| 运行 | 当前配置 | 名称明确；运行时改为重新运行；停止不影响其他配置 |
| 调试 | 当前配置 | 不支持调试时禁用，解释原因；断点暂停与运行中有可读文字 |
| 停止 | 当前配置的活动实例 | 禁用态与可停止态明确；不得含糊变成“停止项目所有任务” |

构建不跟随右侧运行配置变成“构建那个模块”。项目没有可用构建任务时，不摆一个点了才报错的锤子。支持情况从现有任务定义判断；不要另造一套 Maven / Gradle 识别规则。重新构建、打包、清理继续在菜单 / Maven 或 Gradle 工具窗里，主工具栏不横铺一排。

“构建中”按钮反馈表示这个动作不可重复；全局后台任务进度仍归现有状态栏进度原语，不新增第二条进度条。构建失败用现有错误树承接，能定位文件和行。成功不自动关闭用户已打开的结果；停止构建沿用其任务入口，与所选服务的停止按钮分工清楚。
